rSshTerm support

rSshTerm is an SSH client for iPhone: servers in folders, several sessions at once, an extra key row, and every password and key in one vault encrypted on the iPhone.

Getting started

  • Tap + on the Servers screen to add a server, or use Quick Connect to connect without saving it.
  • The first connection to a host asks you to trust its host key. If the key changes later, the app warns you before connecting.
  • Settings › Passwords & Keys: add passwords, import an OpenSSH private key, or generate an ed25519 key and share its public key to add to ~/.ssh/authorized_keys.
  • Settings › Account: keep the encrypted vault in iCloud, sync its key with iCloud Keychain so your other Apple devices open it, and set a master password for when every device is lost.

Known limits

  • RSA keys sign with ssh-rsa (SHA-1), which OpenSSH 8.8 and later refuse by default; use an ed25519 key.
  • Sessions end when the app goes to the background.
  • File transfer (SFTP) is not available yet.
