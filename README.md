# rSshTerm releases

Signed builds of **rSshTerm** (SSH terminal for iPhone, iPad, Linux and macOS) and **rSshD** (the server daemon that
keeps your sessions). Built and published by CI; this repository holds releases only.

- Website and docs: https://rssh.radut.dev
- Latest downloads: [Releases](https://github.com/radut/rsshterm/releases/latest)

Every release carries `SHA256SUMS` and its GPG signature (key `3C2F847F5734F445076275DD5961ADF201732BAC`).
