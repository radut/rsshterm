# Source

rSshTerm's open-source parts, licensed under the Apache License 2.0 (`LICENSE`, `NOTICE`):

| Folder | What |
|---|---|
| `rsshd/` | rSshD, the server daemon that keeps sessions (Go) |
| `desktop/` | the Linux app (GTK 4, libadwaita, VTE) and the shared desktop core (Swift) |
| `apple/Packages/` | RSSHKit and the shared SSH, vault and remote-desktop packages (Swift) |

Third-party code keeps its own licence: see `THIRD_PARTY_NOTICES` in each package and the in-app credits.
The iPhone, iPad and Mac App Store apps are distributed under Apple's standard licence.
