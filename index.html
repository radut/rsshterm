The SSH terminal that keeps your keys in one vault and your sessions on the server.

rSshTerm is a fast, keyboard-first SSH client for iPhone, iPad, Linux and macOS, built from one Swift codebase. Your servers and keys follow you to every device; rSshD keeps your shells alive between visits.

Why rSshTerm

Everything a shell needs, on the device you have with you.

One vault, every device

AES-256-GCM vault opened by each device's own key, iCloud Keychain, or a master password. Face ID and Touch ID after.

Sessions that wait

rSshD keeps each shell in tmux or screen. Lose the network, close the app: resume exactly where you were.

A keyboard for shells

Key row with symbol, navigation and F-key pages, a chip bar, sticky Ctrl/Alt and real word editing.

Files built in

SFTP from inside a session, and a two-pane Commander across the phone, Files, S3 and servers.

Desktop terminal

Tabs, splits, host search and a jump switcher. ssh web1 in any tab picks the vault key.

Remote desktop

VNC and Apple Screen Sharing on Linux and macOS, RDP on Linux, tunnelled over the SSH connection you already have.

Terminal

Type like you are at a desk.

On-screen or on a Magic Keyboard, the keys do what a shell expects.

  • Key row with pages: esc, ctrl, tab and arrows; ⋯ for symbols, PgUp/PgDn/Home/End, F1–F16, META.
  • Chip bar: Paste, Esc, Tab, Shift, Ctrl, Alt, Ctrl+C/D/L, and optional Ctrl+W/U/A/E.
  • Word editing: Natural text editing or Linux presets, Option as Meta per side, hold ← → ⌫ to repeat.
  • Fonts and themes: bundled developer fonts with ligatures and Nerd Font icons, light and dark theme pairs.
Connect

From an address to a saved server in four taps.

  • Quick Connect: paste one host or twenty, pick a user from your list, a key or a password, connect, save to a folder.
  • Network scan: give it 192.0.2.0 and it checks the /24; hosts that answer SSH are one tap from your list.
  • Jump hosts: chain vault servers or inline user@host:port.
  • Agent forwarding with a prompt per use: allow once, for this session, or deny.
rSshD

Close the app. Your shell keeps running.

A small daemon on each server holds your sessions in tmux or GNU screen.

  • Resume one kept session, all of them, or start fresh; choose per server.
  • Timeouts: idle and hard limits per session, and "finish work" waits for the running job.
  • Status at a glance: a chip shows rsshd · tmux, or why sessions are not kept.
  • One-tap install from the app, or one line on the server (below).
Files

Files where the shell is.

  • Session files: the folder button opens the server's files in the shell's current folder, on the same connection.
  • Commander: two panes, any source on each side: phone, Files app, SFTP, S3.
  • F3–F8 view, edit, copy, move, mkdir, delete; a queue with progress and cancel.
Vault

Your keys, sealed once, opened everywhere.

  • Per-device keys: Keychain on Apple devices, Secret Service on Linux; they never leave the device.
  • iCloud Keychain brings the vault to your other Apple devices; Google Drive works on every platform.
  • Master password (scrypt) lets a brand-new device in once; after that it uses its own key.
  • Face ID / Touch ID before keys are shown; saves never overwrite a newer copy from another device.
Desktop · Linux and macOS

A real terminal, with your vault behind every tab.

Local shells in tabs and splits, like iTerm2 or Terminator. The built-in SSH agent serves the vault's keys and writes an ssh_config, so plain ssh web1 just works.

Host search

Ctrl+Shift+K / ⌘K: type part of a name, Enter opens a tab, Shift+Enter a split.

Jump switcher

Ctrl+Shift+J / ⌘J: every open shell, then "new session on" any server.

Self-updating

A signed latest.json drives updates of the tarball, the AppImage and the Mac app; the .deb updates with apt.

Tabs and splits

Cmd/Ctrl+1…9 between tabs, split right or down, focus with Alt+arrows, zoom and equalize. Broadcast what you type to every pane, or pick them. Tabs, splits and SSH panes come back after a restart.

Touch ID on the Mac

The device key sits behind Touch ID; the Mac also opens the iPhone's vault through iCloud.
